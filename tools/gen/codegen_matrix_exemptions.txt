# Codegen compile-matrix exemptions.
#
# One entry per line: <Type> | <reason>
#
# This file records widget types whose to_code product does not compile *today*. It is a measured
# baseline, not a design allowance: every entry here is a type the matrix cannot compile, and every
# entry that becomes compilable must be deleted by hand (the matrix will not notice on its own,
# because an exempted type simply never reaches the compiler). Treat it like
# tools/check/declared_gates_exemptions.txt: shrinking is progress, growing needs a reason.
#
# Two kinds live here as of 2026-11-14:
#   - template / alias types whose construction needs template arguments written out (6),
#   - positional-only constructors with no default form (2).
#
# Both kinds are already reported on stderr by codegen's own note_construction() path. WebView used to
# be a third kind ("constructible but copy and move are deleted, so Node cannot take it by value");
# codegen now emits au::Node{std::make_shared<...>(...)} for such types, so it compiles and left this
# list. Dismissible entered it the same round: the matrix measured that au::Dismissible{} has no
# default form, while is_unconstructible() had been missing it (so no warning was raised).

ThemeProvider | Provider<Theme> alias: construction needs the template argument spelled out
LocaleProvider | Provider<Locale> alias: construction needs the template argument spelled out
MediaQueryProvider | Provider<MediaQuery> alias: construction needs the template argument spelled out
Provider | class template without a default template argument
ReorderableList | class template without a default template argument
Repeater | class template without a default template argument
Hero | positional-only constructor, no default form (au::Hero{} does not compile)
Dismissible | positional-only constructor, no default form (au::Dismissible{} does not compile)
