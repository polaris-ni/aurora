#### #H.14.1 控件可定制性契约（现代化模式）

全部交互控件（`Button`/`Checkbox`/`Switch`/`Slider`/`ProgressIndicator`/`RadioGroup`/`SpinBox`/`TextInput`/
`Dropdown`/`TabBar`/`Chip`/`Badge`/`SegmentedControl`）统一遵循以下四条契约（对标 Qt 属性体系与 Flutter 主题/Style
体系，新增控件必须同样遵守）：

1. **主题回退（theme fallback）**：强调色（`active_color`/`accent_color`/`color`/`focused_border_color` 等） 一律为
   `std::optional<Color>`，未显式设置时绘制期经 `inherit_theme(ctx).primary` 解析（ThemeScope 换肤 即生效），且
   **未设置不序列化**（保留「跟随主题」语义，`to_json`/`from_json` 往返不丢失意图）。
2. **状态反馈与禁用态**：hover/按下统一用 `Color::shaded(k)` 乘性调暗（hover ≈×0.90、0.92，pressed ≈×0.78–0.80）， 淡色底/选区用
   `Color::with_alpha(a)`；所有交互控件提供 `set_enabled(bool)`，禁用态统一灰化绘制、 吞掉指针事件（`e.handled = true`
   不冒泡）且不改值。
3. **继承友好（protected 绘制分阶段钩子）**：`on_paint` 分解为若干 protected 虚函数（如
   `paint_background`/`paint_border`/`paint_label`、`paint_track`/`paint_thumb`、`paint_option`/`paint_item`/
   `paint_tab`/`paint_segment`、`paint_frame`/`paint_box` 等），状态色由 `resolve_*` 钩子解析；成员一律 protected（非
   private），子类可单点覆盖某个绘制阶段而无需重写整个 `on_paint`（参考 `VideoPlayer`/
   `VideoControls` 的四类扩展点先例）。
4. **尺寸/字号/圆角可配**：原硬编码常量（行高、盒高、字号、圆角）升级为可序列化属性（如
   `row_height`/`dot_size`/`box_height`/`item_height`/`tab_height`/`font_size`/`corner_radius`/`track_*`/`thickness`），
   `corner_radius < 0` 统一表示「自动」（胶囊或比例圆角）；影响几何的 setter 调 `mark_needs_layout()`， 仅影响外观的调
   `mark_needs_paint()`。

其他控件本次同步的关键新增属性（均含链式 setter + 序列化往返 + describe 元数据）：

- `RadioGroup`：`active_color`(主题回退)/`border_color`/`text_color`/`dot_size`/`row_height`/`font_size`/`enabled`；钩子
  `paint_option`。
- `SpinBox`：`background`/`border_color`/`text_color`/`arrow_color`/`corner_radius`/`font_size`/`enabled`；上下方向键调节已接线（获焦后
  ArrowUp/ArrowDown）；钩子 `paint_box`/`paint_value`/`paint_arrows`。
- `Dropdown`：`accent_color`(主题回退)/`box_color`/`border_color`/`text_color`/`arrow_color`/`box_height`/`item_height`/
  `font_size`/`corner_radius`/`placeholder`/`enabled`；hover/展开边框高亮；钩子 `paint_box`/`paint_item`。
- `TabBar`：`active_color`(主题回退)/`bar_background`/`tab_background`/`text_color`/`indicator_thickness`/`font_size`/
  `tab_padding`；钩子 `paint_tab`。
- `Chip`：胶囊圆角（`corner_radius`<0 自动）/`text_color`/`delete_color`/`font_size`，hover 调暗；钩子 `paint_background`/
  `paint_content`；`Badge`：胶囊徽章 + `badge_color`/`text_color` 序列化。
- `SegmentedControl`：`active_color`(主题回退)/`text_color`/`selected_text_color`/`border_color`/`font_size`/
  `corner_radius`/`enabled`；`segments` 已序列化（支持完整重建）；钩子 `paint_segment`。

#### 视频播放器（VideoPlayer / VideoSource / VideoControls）

> `media/` 子系统：以抽象 `VideoSource` 为解码扩展点，内置零依赖 `ImageSequenceSource`（图片序列/动画）作为自包含样例与测试基座；
> `VideoPlayer`（继承 `Container`）绘制当前帧 + 叠层控件 + 播放时钟 + 响应式状态；`VideoControls` 为可替换的底部控制条；音频以抽象
> `AudioSink` + `VideoSource` 音频方法暴露，不实现后端。

**核心类（头文件 `include/aurora/media/`）**：

| 类                             | 角色                       | 关键 API                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:-------------------------------|:---------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `VideoSource`（抽象）          | 解码 / 源扩展点            | `open`/`close`/`has_video`/`has_audio`/`natural_size`/`duration`/`play`/`pause`/`seek`/`position`/`set_volume`/`set_muted`/`frame_at(pos)`；推模型 `set_frame_callback`/`set_audio_callback`/`set_state_callback`                                                                                                                                                                                                                                             |
| `ImageSequenceSource`          | 内置零依赖源（图片序列）   | `set_frames`/`append_frame`/`set_fps`/`open`（`;``\|` 分隔的多图路径）                                                                                                                                                                                                                                                                                                                                                                                        |
| `VideoPlayer`（`Container`）   | 播放器控件（可子类化）     | `set_source`/`set_fit(BoxFit)`/`play`/`pause`/`toggle_play`/`seek_fraction`/`set_volume`/`set_muted`/`set_show_controls`/`set_controls`/`create_default_controls`(virtual，挂载期生效)/`set_on_tap`/`set_on_double_tap`；受保护可覆写 `on_frame`/`on_playback_tick`/`on_tap`/`on_double_tap`/`on_paint`/`on_layout`/`on_mount`；受保护 `current_frame()` 读当前帧、`paint_frame()` 复用绘制；`on_pointer_event`/`wants_click` 为 public（对齐 `Widget` 基类） |
| `VideoControls`（`Container`） | 可替换控件叠层             | 默认 `[播放][进度(撑满)][时间][静音][音量]`；构造接收 `VideoController*`；受保护访问器 `play_button()`/`time_text()`/`mute_button()` 供子类换肤 / 重排；`build_children()` 为 virtual，子类覆写可整体定制控件条                                                                                                                                                                                                                                               |
| `AudioSink`（抽象）            | 音频输出扩展点（App 实现） | `play_samples`/`set_volume`/`set_muted`                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `VideoController`（接口）      | 控件与播放器解耦           | `toggle_play`/`seek_fraction`/`set_volume`/`set_muted`/`is_playing`/`position_fraction`/`duration` + `Reactive` 信号指针                                                                                                                                                                                                                                                                                                                                      |

**四类扩展点（「易于继承定制」）**：

1. **可插拔解码 / 源**：继承 `VideoSource` 实现 `frame_at` + 播放控制，即可接入 ffmpeg / 平台媒体 / 相机 / 网络流；内置
   `ImageSequenceSource` 为最小参考实现（无三方依赖）。
2. **可子类化播放器本体**：覆写 `on_frame`（滤镜 / 叠加）、`on_playback_tick`（自定义时钟）、`on_paint`/`on_layout`
   （自定义渲染与布局）；子类 `on_paint` 可通过受保护 `current_frame()` 读取当前解码帧、经 `paint_frame()`
   复用默认帧绘制后再叠加水印 / 滤镜；`create_default_controls()` 为 virtual，在挂载期（`on_mount`，且控件叠层为空时）被调用，故子类覆写真正生效，
   `set_controls` 构造后替换仍优先。
3. **可定制控件 UI**：`set_controls(...)` 整体替换叠层；默认 `VideoControls` 可被继承换肤 / 重排——通过受保护
   `play_button()`/`time_text()`/`mute_button()` 访问子控件，或覆写 virtual `build_children()` 重建控件条（
   `VideoPlayer::on_pointer_event`/`wants_click` 已恢复为 public，与 `Widget` 基类一致）。
4. **可插拔事件 / 手势**：覆写 `on_tap`/`on_double_tap`，或设置 `set_on_tap`/`set_on_double_tap` 回调（默认单击 =
   play/pause、双击 = 切换适配模式）。

**播放时钟**：由 `Application::tick` 经 `Widget::tick_gestures` 逐帧驱动；`VideoPlayer` 在 `on_playback_tick` 按
`steady_clock` 推进播放位置、向源拉取帧并缓存，逐帧仅 `mark_needs_paint`（不触发整树重排）。`Reactive` 状态 `playing`/
`progress`/`volume`/`muted` 供控件与 UI 绑定。

**音频**：`VideoSource` 暴露 `set_volume`/`set_muted` 与 `set_audio_callback`（推送 16-bit PCM）；具体输出由 `AudioSink`抽象交给
App（OpenAL / WASAPI / AAudio…）；`ImageSequenceSource` 无音频（`has_audio()==false`，音频方法 no-op）。
